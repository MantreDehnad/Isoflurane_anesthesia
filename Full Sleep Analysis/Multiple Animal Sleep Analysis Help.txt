Multiple Animal Sleep Analysis Help
created by Roshan Nanu, 2014

This Program is used for the analysis of xlsx outputs from the Single Animal
Sleep Analysis Program. 

In this program you can input data from multiple animals and generate an
excel file with a Cumulative SWS sheet, a sheet for each animal containing
Delta Power for NREM bouts greater than a chosen duration in length and a
sheet containing the natural log of the delta power normalized to the
average baseline gamma power of each animal. Additionally, you can use this
program to fit the SWA decay of an average SWS episode across all animals. 
The results of this fitting wil be saved to the same excel file as the rest
of the data.  

____________________________________________________________________________

Usage

		1) Choose the number of animals you wish to use in the analysis.
		2) Select the proper epoch duration.
		3) Select the minimum length of episodes to be retained for the 
			SWA Decay fitting.
		4) Select whether the data is baseline or sleep deprivation
		5) Push 'Choose Files' and Selected all Files.
			Be sure to read the notice about how the input files should be
			formatted if they were not created with the Single Animal 
			Sleep Analysis Program. 
		6) Assign Animal ID numbers to each file
			- You may do this when prompted after file selection or manually
			using the 'Change ID' button.
		7) If the files contain SD data, use the 'Change Gamma' button to
			assign Average 24hr Baseline Gamma Power for each file.
		8) Press the 'Create Output' button.
		9) Select output file when prompted.
		
	Fitting SWA
		1) After doing the above, press the 'Fit SWA Decay' button.
		2) Select the fragment you wish to fit using the pop-up window.
			-The fit results will then be displayed and saved to the excel
			file
		3) Save the fit figure if you want to. 
		4) To re-do the fit simply press the 'Fit SWA Decay' button again.
		5) At the end you will be shown both fit results and asked which
			you want to keep. You may repeat this as much as you want.
